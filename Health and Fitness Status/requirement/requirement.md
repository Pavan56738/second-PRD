**Project Title:** Health and Fitness Evaluation System

## Requirement

Develop a Java console application that evaluates a person's basic health and fitness using hard-coded data. The program should store personal details such as name, age, height, weight, daily activity hours, water intake, and sleep hours. It must calculate the Body Mass Index (BMI), determine the BMI category, evaluate activity, water intake, and sleep status, and display the overall fitness status along with an appropriate improvement message. The application should process at least two profiles using a **while** or **do-while** loop and demonstrate the use of arithmetic operators, type casting, decimal division, relational operators, logical operators, **if-else-if**, the **ternary operator**, and looping constructs.
